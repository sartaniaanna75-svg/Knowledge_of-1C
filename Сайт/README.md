# Сайт инструкций для сотрудников

Вариант **1+4**: локальный HTML-сайт + вход по ролям.

## Как открыть

1. Дважды щёлкните `Открыть_сайт.bat`  
   или откройте `index.html` в браузере.
2. Выберите роль на главной.
3. Читайте инструкцию, пользуйтесь поиском и меню слева.

## Состав

| Файл | Назначение |
|---|---|
| `index.html` | Главная с выбором роли |
| `guide.html` | Страницы инструкций |
| `assets/content.js` | Текст всех инструкций |
| `assets/styles.css` | Оформление |
| `assets/guide.js` | Навигация и поиск |

## Как обновить текст

1. Правите нужный файл в `02_Рабочие_инструкции/База_знаний/`.
2. Перенесите изменения в соответствующий блок `assets/content.js`.
3. Обновите страницу в браузере (F5).

## Доступ для сотрудников

Скопируйте папку `Сайт` на общий диск или отправьте ярлык на `Открыть_сайт.bat`.
